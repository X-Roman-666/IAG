<h1 align="center">IAG</h1>

<p align="center"><strong>Investigation-Augmented Generation · 调查增强生成</strong></p>

我们正在研究一种叫 **IAG——调查增强生成（Investigation-Augmented Generation）** 的 AI 协作方法。

RAG 通过检索外部资料，帮助模型获得回答所需的知识。但在实际项目中，即使资料充分，AI 仍可能做出不适合用户的成果：它可能不了解用户的真实目的、行业处境、已有经验和具体困难，而用户自己也可能在交流过程中，才逐渐明确想要什么。

IAG（Investigation-Augmented Generation，调查增强生成）是一种以调查驱动的生成与协作技术框架。系统围绕用户及其实际问题，持续调查目标、认知、情境、历史与已有成果，主动选择询问、检索、观察和验证等行动，并根据获得的证据及用户反馈，更新共同理解、生成内容和执行方案。

IAG 希望把“调查”贯穿整个工作过程。AI 一边了解用户和实际问题，一边调查现状、历史及已有成果，帮助用户理解可选方案和关键取舍，再根据交流与执行反馈不断调整判断、推进任务。信息足够时直接行动，出现关键未知时再调查，避免把协作变成开场问卷。

我们吸收了两条指导思想：**“善假于物”**，意味着主动寻找并利用已有工具、成果和实践经验；**“调查就是解决问题”**，意味着深入了解具体情况，让事实和反馈不断修正方案。同时，把人放在中心，让用户能够理解、参与并决定自己的目标。

目前，我们已经通过 **DSH Collaborator 插件**实现了初步机制，包括共同理解记录、相关成果查找指导，以及持续交流提醒。接下来要进一步明确调查行动的选择与更新机制，并验证它能否改善成果适用性、减少返工和用户负担。
